# Nearclip 1.2 release verification — 2026-10-29 (KST)

## Release artifacts

- App runtime changes are the previously validated `15306ee` implementation. Release preparation `67a50fc` adds release notes, clean MSIX packaging and PRI preflight checks; it does not change app runtime behavior.
- Native macOS and iPhone/iPad archives were produced with released Xcode 27.1 (`27A9275`). All Apple app bundles use 1.2.0, build 3; Android uses 1.2.0, version code 5; Windows packages use 1.2.0.0.
- Developer ID macOS archive was uploaded for notarization and exported with `xcodebuild -exportNotarizedApp`. `codesign --verify --deep --strict`, `stapler validate`, and `spctl --assess --type execute` passed; Gatekeeper reported `Notarized Developer ID`.
- Mac App Store and iOS/iPadOS uploads both returned `Uploaded` and `EXPORT SUCCEEDED`. Upload success alone does not establish processing, review submission, approval or Store publication.
- The public sideload IPA contains the main app and `NearclipShare.appex`, both supporting iPhone and iPad. It has no embedded provisioning profiles or test host. Its actual version, bundle metadata and checksum were checked. Physical AltStore/SideStore re-signing and installation were not tested.
- Android release APK is signed with the existing Nearclip release key. Both portable Windows architectures were rebuilt. MSIX bundle identity, architecture, version, CRC and native bridge inclusion were checked.
- The SHA-256 manifest was rechecked against all five direct-download artifacts before publication.

## Additional Windows regression checks

One initial cold-start Windows VM test run failed while waiting for group-key convergence in `RemovalRotatesOnlinePeersAndOldOfflineKeyCannotReconnect`. The failure was not reproduced in 15 targeted retries, a further 50 targeted repetitions with engine-error logging, or 15 complete runs of the 60-test suite (900 passing test executions). The original failure's precise cause remains unconfirmed; it is not reported as a fixed runtime defect.

Microsoft's first upload rejected manifest logos: all 72 image files existed, but an unpackaged build's cached PRI had been reused and contained no `Files/Images` entries. Cleaning the Store configuration before publishing regenerated the entries on both architectures. The new preflight validates the packaged PRI identity, all six manifest logo resources and every referenced image candidate. It accepted both corrected packages and rejected the original stale package. The corrected bundle passed Partner Center upload validation and was saved as version 1.2.0.0.

All three jobs of the [release-preparation CI](https://github.com/ivLis-Studio/nearclip/actions/runs/40726464509) passed, including iPhone simulator sharing acceptance. It includes both native Store packages after an unpackaged build. Its Windows job passed the new preflight for x64 and Arm64 and retained the resulting bundle as an artifact. The previously completed [implementation validation](2026-10-28.md) covers 119 unit tests, 60 interoperability scenarios, simulator transfer acceptance and 244 website checks. The six source-generator tests passed again for release preparation.
