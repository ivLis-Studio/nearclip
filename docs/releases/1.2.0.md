# Nearclip 1.2

## 한국어

- iPhone·iPad의 시스템 공유 메뉴에서 텍스트, 링크, 이미지를 골라 지정한 기기로 전송합니다.
- 기기별로 보내기, 받기, 이미지, 인증번호 동기화를 설정합니다. 지정한 수신 대상은 중계와 기록 복구에서도 유지됩니다.
- 인증번호는 수신 시점이 아닌 원래 생성 시점부터 3분 뒤 만료됩니다. 자동 정리할 때 이후 복사한 클립보드 내용을 지우지 않습니다.
- 로컬 기록과 이미지·긴 텍스트를 암호화합니다. 기기를 해제하면 새 그룹 키를 남은 온라인 기기에 전달합니다.
- Mac·Android 설정에서 업데이트를 확인하며, iPhone·iPad는 AltStore·SideStore 소스를 지원합니다.
- Android 기기별 설정에서 항목 전체를 눌러 스위치를 조작할 수 있고, iOS의 기존 이미지 공유 방식도 처리합니다.

**업데이트 안내:** 연결된 기기를 모두 1.2로 업데이트하는 것을 권장합니다. 제한된 공유는 새 기능을 지원하는 기기에만 전송합니다. 기기 해제 시 오프라인이거나 이전 버전인 기기는 다시 페어링해야 합니다. 암호화된 1.2 기록은 1.1에서 읽을 수 없습니다.

iOS는 다른 앱의 알림을 읽거나 백그라운드 클립보드를 감시할 수 없습니다. 원격 공유는 메인 앱의 내장 Tailscale 연결이 활성 상태여야 합니다. 새 전송 완료 알림은 추가하지 않았습니다.

## English

- Send text, links and images to a selected device from the iPhone and iPad system share sheet.
- Set send, receive, image and verification-code preferences for each device. Recipient restrictions survive relaying and history catch-up.
- Verification codes expire three minutes after their original creation. Cleanup preserves anything copied afterward.
- Encrypt local history, images and long text. Removing a device rotates the group key for the remaining online devices.
- Check for updates quietly in Mac/Android settings, and install iPhone/iPad updates through an AltStore or SideStore source.
- Improve Android setting-row accessibility and handle legacy UIKit image providers on iOS.

**Upgrading:** Update paired devices to 1.2 together. Restricted sharing requires compatible recipients. Devices that are offline or running older versions when another device is removed must be paired again. Version 1.1 cannot read the encrypted 1.2 history format.

iOS cannot read other apps' notifications or continuously monitor the background clipboard. Remote sharing requires the main app's embedded Tailscale connection to remain available. No additional transfer-receipt notifications were added.

See [behavior, compatibility and validation](../validation/2026-10-28.md). Direct-download availability and Store review/publication are separate distribution states.
